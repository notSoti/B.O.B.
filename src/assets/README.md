## Emoji Assets
This folder contains the emoji assets used by the bot. You have to upload them manually as [Application Emojis](https://discord.com/developers/applications/select/emojis) in the Discord Developer Portal for your bot application.

> [!IMPORTANT]
> The emoji names must match the file names (without the file extension) for the bot to recognize them correctly. For example, `success.png` should be uploaded as an emoji named `success`.
